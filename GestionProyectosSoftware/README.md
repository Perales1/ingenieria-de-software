# Proyecto "Shattered Path" - Gestión de Proyectos Software

## Descripción del Repositorio
Este repositorio contiene la documentación generada para la simulación de la creación y gestión de un videojuego titulado **"Shattered Path"**. Este proyecto ha sido desarrollado como caso práctico para la asignatura de **Gestión de Proyectos Software**.

El objetivo de esta simulación no es el desarrollo del código del juego en sí, sino aplicar las metodologías, herramientas y buenas prácticas de gestión integral de un proyecto de software, operando bajo el nombre del estudio ficticio **Eclipse Forge Studios**. 

A través de la documentación adjunta, se aborda el ciclo de vida completo del proyecto: desde la concepción y diseño del producto, pasando por la planificación iterativa, la asignación de recursos humanos y tecnológicos, hasta la viabilidad y gestión financiera.
