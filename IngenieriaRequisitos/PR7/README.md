# Práctica 7: Modelo del Dominio - Sistema de Gestión de Gimnasio

Este repositorio contiene la documentación y el desarrollo del **Modelo del Dominio** para un sistema de gestión integral de un gimnasio, realizado como parte de la asignatura de Ingeniería de Requisitos (Universidad de Jaén).

## Descripción del Proyecto

El objetivo de esta práctica ha sido elaborar un modelo de dominio robusto y detallado mediante la aplicación rigurosa de dos técnicas principales de extracción de requisitos y modelado conceptual. El dominio de estudio abarca desde la gestión de rutinas y reservas por parte de los usuarios, hasta el mantenimiento de instalaciones, la gestión del personal (monitores) y la impartición de clases dirigidas.

## Estructura del Trabajo

El documento principal de la práctica detalla las siguientes fases de desarrollo:

### 1. Análisis Lingüístico de Escenarios
Se ha realizado una exhaustiva extracción de clases conceptuales, atributos y asociaciones a partir de 14 casos de uso específicos del sistema, entre los que destacan:
* Entrenamiento y reservas en el gimnasio.
* Gestión de los servicios ofrecidos y plantilla de monitores.
* Supervisión del mantenimiento del gimnasio y subcontratación de trabajos.
* Asignación y gestión de rutinas de usuarios.
* Supervisión de entrenamientos en instalaciones y en exteriores.

### 2. Observación Basada en Listas de Categorías
Se ha llevado a cabo una revisión del contexto del dominio aplicando listas de categorías para identificar elementos clave, clasificándolos en:
* Objetos tangibles físicos y lugares.
* Roles de los participantes.
* Transacciones de datos y hechos observables.
* Reglas, políticas y sistemas externos.

### 3. Unificación y Glosario
Integración de los resultados de las dos técnicas anteriores en una **Lista Unificada** de clases, atributos y asociaciones, eliminando redundancias y consolidando la información. Se incluye además un **Glosario de términos** para definir formalmente los conceptos fundamentales del sistema (como Administrador, Usuario, Monitor, Reserva, etc.).

### 4. Modelo del Dominio (Diagrama UML)
El trabajo culmina con la representación gráfica del modelo del dominio mediante un diagrama de clases UML. Dado el volumen de clases identificadas, el diagrama presenta una visión resumida e integral con las entidades y relaciones más importantes que rigen la lógica de negocio del gimnasio.

## Herramientas Utilizadas
* Análisis y extracción de requisitos metodológica.
* Herramientas de modelado UML para la creación del diagrama de clases (modelo del dominio).
