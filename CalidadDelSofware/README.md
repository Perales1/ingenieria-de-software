# Aplicación de Métricas del Software

**Asignatura:** Calidad del Software  
**Grado:** Grado en Ingeniería Informática  
**Universidad:** Universidad de Jaén (Curso 2024/2025)  
**Autores:** David Lorente Wagner y David Fernández Espejo  

---

## Descripción General

Este repositorio documenta el trabajo de refactorización, análisis estático y aplicación de métricas de calidad de software sobre una base de código en C++. El proyecto original corresponde a un caso práctico de Programación Orientada a Objetos (POO) estructurado en torno a las clases `Piloto`, `Droide` y `Starfighter`, evaluando sus relaciones de asociación e integridad de punteros.

El objetivo principal radica en incrementar la calidad, robustez y mantenibilidad del software aplicando **estándares de codificación CERT C++**, corrigiendo incidencias detectadas con **CPPCheck** y reduciendo la complejidad ciclomática calculada mediante **Metriculator**.

---

## Herramientas y Estándares Utilizados

* **Lenguaje:** C++
* **Analizador Estático:** `CPPCheck`
* **Medición de Métricas:** `Metriculator` (Complejidad Ciclomática de McCabe y LSLOC)
* **Estándares de Codificación:** Normas **CERT C++**
