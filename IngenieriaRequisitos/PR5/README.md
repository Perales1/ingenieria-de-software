# Práctica 5 - Ingeniería de Requisitos: Modelos Orientados a Objetivos

## Descripción del Proyecto
Este proyecto contiene la resolución de una práctica de Ingeniería de Requisitos centrada en el modelado orientado a objetivos utilizando el framework **i-Star**. El dominio de aplicación es el sistema de gestión de un gimnasio, modelando las interacciones, dependencias y objetivos de los diferentes actores (stakeholders) involucrados en su funcionamiento.

## Contenido
El trabajo documenta tanto gráficamente como en lenguaje natural (mediante el uso de plantillas estandarizadas) los requisitos del sistema. Incluye:

1. **Modelo de Dependencias Estratégicas (SDM):** Una visión global de cómo los diferentes actores dependen unos de otros para alcanzar sus objetivos.
2. **Modelos de Razonamiento Estratégico (SRM) Parciales:** Análisis detallado de los objetivos (Hardgoals y Softgoals) y tareas internas de cada actor principal:
   * **El Administrador:** Gestión de recursos, control de reservas y plantilla.
   * **El Usuario:** Objetivos de bienestar físico, flexibilidad y alternativas de entrenamiento.
   * **El Monitor:** Impartición de clases, gestión de rutinas y supervisión.
   * **El Técnico de Mantenimiento:** Mantenimiento de instalaciones operativas, orden y limpieza.
3. **Documentación en Lenguaje Natural:** Fichas detalladas para al menos 1 Hardgoal, 1 Softgoal y 3 Tareas por cada uno de los stakeholders mencionados, justificando prioridades, dependencias y descripciones funcionales.

## Herramientas Utilizadas
* **Metodología:** Modelado i-Star.
* **Software de Modelado:** OpenOME (exportado como proyecto general).
* **Documentación:** Plantillas tabulares para especificación de requisitos.
